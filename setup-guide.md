# ⚙️ Home Assistant Setup Guide

## 🖥️ System
- OS: Debian Linux
- Deployment: Home Server (VM or physical)
- Access: SSH + Web UI

---

## 🔧 Installation Steps
1. Install Debian Linux
2. Update system packages
3. Install Home Assistant (Docker or supervised install)
4. Configure network access
5. Enable SSH for remote management

---

## 🌐 Network Configuration
- Static IP for Home Server
- Router port forwarding (if remote access needed)
- Local access via LAN

---

## 🔐 Security Basics
- Disable unnecessary services
- Use strong SSH keys
- Limit exposed ports
- Keep system updated

---

## 📌 Purpose
This setup is used for:
- Learning Linux administration
- Practicing networking concepts
- Building automation systems
- Self-hosting services
